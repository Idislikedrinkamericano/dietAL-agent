# 🍱 DietAL Agent

A small LangGraph nutrition-tracking agent. It parses meal descriptions, normalizes quantities to grams, calculates nutrition from a deterministic food database, stores today's log, and gives goal-aware feedback.

## V2

The nutrition engine is now gram-based:

```text
natural language
→ food + quantity/unit
→ normalize to grams
→ per-100g nutrition
→ daily totals
→ feedback
```

Examples:

```text
200g鸡胸肉
两个鸡蛋
一碗半米饭
半杯拿铁
一个汉堡
```

Household units use explicit default gram assumptions and the output tells you when an estimate was used.

## Run

```bash
git clone https://github.com/Idislikedrinkamericano/dietAL-agent.git
cd dietAL-agent
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python demo.py
```

Commands:

```text
/today   show today's totals
/goals   show daily goals
/undo    undo the last food item
/reset   clear today's log (useful while testing)
quit     exit
```

## Optional LLM parser

Set `OPENAI_API_KEY` to let the LLM parse flexible natural language into food + grams. Nutrition values are never generated by the LLM; calculation stays deterministic.

## Important limitations

- Nutrition values are approximate demo values, not clinical data.
- “one bowl / one cup / one piece” has no universal weight, so household-unit conversions are assumptions.
- Branded restaurant items and mixed dishes still need a real nutrition data source for better accuracy.
- A generic “hamburger” uses a generic estimate; a named restaurant product should eventually use a product-specific database/API.

Next steps: external nutrition data source, editable goals, correction flows, richer memory, and image input.
